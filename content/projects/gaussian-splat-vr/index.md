**VR rendering.** A workflow for bringing Gaussian splats into VR environments using Gracia AI and Unreal Engine, achieving real-time rendering at 60 FPS with 25x lossless compression. The aim was better scalability and photorealism for medical simulation, education and retail.

**Humanoid robotics.** An API connecting a humanoid robot to a custom ChatGPT model for real-time, context-aware conversation. I collected data on interaction patterns, task execution and user engagement as a foundation for AI-assisted robotics in healthcare, education and customer service.
